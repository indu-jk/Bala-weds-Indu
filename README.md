# Bala weds Indu

A sample wedding invitation for Bala and Indu, designed to open beautifully from a WhatsApp link.

## Preview

Run `python -m http.server 5190 --bind 127.0.0.1` from this folder, then open http://127.0.0.1:5190/.

This is a buildless HTML/CSS/JavaScript website. No account, backend, analytics, or dependencies are required. All illustration assets are original SVG artwork included in the repository.

## Before sharing the real invitation

This version is labelled **Design preview**. Names are supplied by the requester; the wedding date, times, venue and RSVP contact are intentionally not invented. Replace the `wedding` settings in `script.js` to add confirmed details. The sample announcement dialog does not collect or send guest details.

GitHub Pages should publish from `main` at `/` with `.nojekyll`. Site URL: https://indu-jk.github.io/Bala-weds-Indu/ . The repository owner may need to enable Pages under Settings → Pages if a collaborator cannot enable it.

## Design

Warm ivory paper, deep burgundy, muted foliage green and antique gold. Editorial serif names, quiet sans-serif supporting text, original pavilion illustration, responsive event sections, optional reduced-motion support, accessible native dialog and a share/copy-link action. A local PNG preview is used in Open Graph tags for messaging previews. WhatsApp controls whether and when it caches/displays a link preview.
